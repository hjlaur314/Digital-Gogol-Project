# The Digital Gogol Project
## About 
The Digital Gogol Project is a digital humanities project involving the computational analysis of the short stories of Nikolai Gogol. It is a project about both the writer himself and the context of his writing, as well as the process of applying digital methods to literary texts. 
## Project Goals
- Encode all of Gogol's Petersburg tales following TEI guidelines.
- Document the process of encoding the texts.
- Create tutorials for the project blog.
